# ADR｜行为面试：宋闻书 / 知识库与技术文档工程师

## 状态
提议中

## 背景
HR 与相关岗位 Agent 对候选 Agent 进行行为面试，重点考察 STAR、协作边界、工具调用安全和独立判断能力。技能缺口：知识库与技术文档缺口

## 决策
采用可审计、可回滚、可检索的内部资源流转机制。

## 方案
- Agent 通过工具生成文档/代码/运行结果
- 资源写入内部共享空间
- 关键资源进入知识库和公共记忆池
- 高风险动作禁止自动执行

## 影响
- 提升公司模拟真实性
- 便于面试讲解 Agent Runtime 的工程闭环

## 回滚
恢复到上一版工具注册表与资源索引即可。
